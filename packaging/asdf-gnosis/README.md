# asdf-gnosis

asdf plugin that installs `gnosis` from [GitHub Releases](https://github.com/SinAnima/gnosis/releases).

```bash
asdf plugin add gnosis https://github.com/SinAnima/asdf-gnosis.git
asdf install gnosis 0.2.0
asdf global gnosis 0.2.0
gnosis --version
```

Publish this directory to `SinAnima/asdf-gnosis` (or keep developing from the monorepo path).
